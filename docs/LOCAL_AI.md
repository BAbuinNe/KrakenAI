# KrakenAI — локальная нейросеть

Вместо обучения большой модели с нуля используем Qwen2.5 7B Instruct через Ollama. Локальная LLM помогает искать смысловые совпадения и отвечает в чате; числовые характеристики проверяет независимый Python-анализатор. В документах не выполняются команды, а неподтверждённые совпадения не становятся окончательным выводом.

## Запуск

1. Скопируйте `.env.example` в `.env`. Задайте уникальный `APP_PASSWORD` длиной от 16 символов. Не коммитьте `.env`.
2. Выполните `docker compose -f compose.local.yml up -d --build`.
3. Загрузите модель: `docker compose -f compose.local.yml exec ollama ollama pull qwen2.5:7b-instruct`.
4. Откройте http://127.0.0.1:8000 и введите пароль.

Ollama в Docker доступен только по внутренней сети, API-приложение — только через 127.0.0.1. На CPU 7B может отвечать медленно; для лёгкого ПК используйте модель `qwen2.5:3b`. Для сетевого/удалённого доступа нужен отдельный HTTPS reverse proxy и меры безопасности.

## Порядок анализа

1. Загрузить ТЗ и до десяти КП.
2. Ограниченным по ресурсам процессом извлечь текст и таблицы.
3. Нормализовать числовые требования, сравнить по `pass/fail/unknown`.
4. Передать языковой модели недоверенные фрагменты документа только для предварительного смыслового анализа.
5. Проверить цитаты модели на дословное совпадение с исходными фрагментами. Все нечисловые выводы требуют проверки специалиста.

## Ограничения текущего пилота

Пока нет OCR для отсканированных PDF/фото, постоянного Postgres-хранилища, индивидуального RBAC, аудита ручных правок и подтверждённого соответствия 152-ФЗ. Не загружайте конфиденциальные коммерческие документы в общедоступную демонстрацию. Бесплатные CPU-хостинги не подходят для быстрой локальной инференции 7B.

`OLLAMA_URL` допускает только три локальных DNS-имени/IP и точный путь `/api/chat` на порту 11434: клиентское содержимое не может задать произвольный адрес запроса.

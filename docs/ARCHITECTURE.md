# План архитектуры KrakenAI

1. **UI:** лёгкий адаптивный AI-чат, загрузка документов, отдельный экран сравнений. Темы светлая/тёмная.
2. **Загрузка:** PDF, DOCX и XLSX только через backend с ограничениями размеров, проверкой сигнатур и защитой от zip-bomb.
3. **Извлечение:** обработка в изолированном worker без доступа к секретам; OCR сканов — отдельный этап.
4. **Нормализация:** преобразование характеристик и единиц измерений, выделение обязательных требований.
5. **Сравнение:** детерминированная проверка чисел; состояния pass/fail/unknown, где unknown не равно pass.
6. **AI:** внешний LLM API только для смыслового сопоставления и объяснения; модель не может менять результаты точных проверок.
7. **Аудит:** источники со страницами и цитатами, предупреждения об отсутствии данных, отчёты с проверяемыми основаниями.
8. **Секреты и доступ:** аккаунты, ограничение ролей, CSRF/CORS, защищённые cookies, rate limits, безопасные логи.
9. **Релиз:** CI с тестами и security scans, staging, внешний пентест и ручная проверка результатов.

**Демо, загруженное сейчас, — только визуальный фронтенд.**

# KrakenAI — интеллектуальный анализ предложений поставщиков

**Пилотная версия**, предназначенная для тестирования на искусственных документах.

- Фронтенд: чат с Kraken, белая и тёмная темы, анимированные щупальца, отдельный экран аналитики. Исходники: app/static/.
- Backend: Python + FastAPI, проверка входа, загрузка PDF/DOCX/XLSX/TXT (до 5 МБ), ограниченный worker-парсер, история и отчёты PDF/CSV/JSON.
- Анализ: детерминированное сравнение поддерживаемых числовых критериев. Неизвестные параметры помечаются needs review.
- Опциональный AI: внешний OpenAI-compatible Chat Completions API для предварительного семантического анализа. **Без ключа — только rule-based анализ и шаблонные ответы.**

## Запуск

Требуется Python 3.12+.

1. Скопируйте .env.example → .env и замените APP_PASSWORD на случайный пароль длиной не менее 16 символов.
2. Запустите:

    pip install -r requirements.txt
    APP_PASSWORD='YOUR_LONG_RANDOM_PASSWORD' python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

3. Откройте http://127.0.0.1:8000 и введите пароль.

Windows PowerShell:

    $env:APP_PASSWORD = "ВАШ_СЛУЧАЙНЫЙ_ПАРОЛЬ_ОТ_16_СИМВОЛОВ"
    python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

Или: docker compose up --build -d (с правильно настроенным .env).

Тесты: pip install pytest; pytest -q.

## Подключение AI

Секреты только на сервере, в .env/защищённых переменных окружения:

    AI_MODEL=model
    AI_API_KEY=your-secret
    AI_CHAT_COMPLETIONS_URL=https://provider.example/v1/chat/completions

AI-модель получает фрагменты коммерческих документов; перед отправкой реальных данных необходимо получить разрешение и проверить условия хранения у провайдера.

## Что можно проверить

Загрузите ТЗ и 1–5 КП в формате PDF/DOCX/XLSX/TXT, откройте «Аналитика», посмотрите pass/fail/unknown и скачайте отчёт. Например, «Мощность не менее 5 кВт; Гарантия от 24 мес» и разные предложения.

## GitHub / хостинг

index.html в корне — **статический демо-предпросмотр** (показывает пример чата, но не обрабатывает документы). Рабочий интерфейс находится в app/static/index.html и предназначен для запуска вместе с FastAPI. GitHub сам по себе не запускает Python-сервер; для доступного из интернета приложения нужен HTTPS reverse proxy + сервер/контейнер.

## Безопасность

Это **не готовый к публичному использованию многопользовательский SaaS**. Имеется один общий пароль для тестового рабочего пространства, данные хранятся временно в памяти, нет MFA, RBAC и внешнего пентеста. Подробнее: SECURITY.md. Не загружайте реальные конфиденциальные предложения в публичные демонстрационные окружения. Результат анализа требует проверки специалистом.


## Локальная нейросеть — Ollama

Режим без облачного API: `compose.local.yml` + Qwen2.5 7B Instruct. Запуск, ограничения и меры защиты описаны в [docs/LOCAL_AI.md](docs/LOCAL_AI.md). Система рассчитана на **до 10 КП** в одной загрузке. Важно: для текущей версии проверки числовых критериев детерминированы, нечисловые замечания языковой модели предварительны; журналы правок и соответствие 152-ФЗ пока не реализованы.

## Быстрое устранение тайм-аутов Gemini (пилот)
Статус «AI настроен» означает только наличие настроек, а не ответ Google.
Если основная модель недоступна, можно установить на сервере
`GEMINI_FALLBACK_MODEL=gemini-3.5-flash-lite`.
После сетевой паузы примерно 30 секунд или HTTP 502/503/504 система пытается
получить ответ через резервную модель. Ошибки ключа 401/403 и лимита 429
**не обходятся**; API-ключ остаётся на Render. После выдачи первой части ответа
автоматического переключения модели нет во избежание дублирования.
Резервная модель может иметь другую стоимость, доступность и качество ответов.
При анализе закупок выводы AI остаются предварительными, а числовые проверки
выполняет `app/analysis.py`.

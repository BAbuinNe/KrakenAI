# KrakenAI

KrakenAI — веб-интерфейс AI-помощника для сравнения коммерческих предложений поставщиков.

## Текущая публикация

- `index.html` — интерактивное демонстрационное приложение в стилях светлой и тёмной темы с анимированным кракеном и щупальцами.
- В демо нет реального AI, загрузки или сохранения документов. **Не загружайте конфиденциальные файлы** в статический предпросмотр.
- Реальная проверка ТЗ и коммерческих предложений — серверная часть следующего этапа, с авторизацией и безопасным хранением.

## Дизайн

Плоские белый/графитовый фоны, чёрный текст и красные акценты без градиентов. Чат — главный экран; аналитика — отдельный раздел. Анимации не должны препятствовать вводу, а для `prefers-reduced-motion` движение сокращается.

## Локальный запуск предпросмотра

Откройте `index.html` в браузере. Для локального сервера: `python -m http.server 8000`.

## Важно

Это публичный демо-фронтенд, а **не production-сервис для хранения коммерческих документов**. Перед подключением реальных пользователей необходимы авторизация, защищённый backend, контроль доступа, тесты и независимая проверка безопасности.

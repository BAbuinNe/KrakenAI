# KrakenAI — интеллектуальный анализ предложений поставщиков

**Пилотная версия**, предназначенная для тестирования на искусственных документах.

- Фронтенд: чат с Kraken, белая и тёмная темы, анимированные щупальца, отдельный экран аналитики. Исходники: app/static/.
- Backend: Python + FastAPI, проверка входа, загрузка PDF/DOCX/XLSX/TXT (до 5 МБ), ограниченный worker-парсер, история и отчёты PDF/Excel/CSV/JSON.
- Анализ: детерминированное сравнение поддерживаемых числовых критериев. Неизвестные параметры помечаются needs review.
- Опциональный AI: внешний OpenAI-compatible Chat Completions API для предварительного семантического анализа. **Без ключа — только rule-based анализ и шаблонные ответы.**

## Запуск

Требуется Python 3.12+.

1. Скопируйте .env.example → .env и замените APP_PASSWORD на случайный пароль длиной не менее 16 символов.
2. Запустите:

    pip install -r requirements.txt
    APP_PASSWORD='YOUR_LONG_RANDOM_PASSWORD' python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

3. Откройте http://127.0.0.1:8000 и введите пароль.

Windows PowerShell:

    $env:APP_PASSWORD = "ВАШ_СЛУЧАЙНЫЙ_ПАРОЛЬ_ОТ_16_СИМВОЛОВ"
    python -m uvicorn app.main:app --host 127.0.0.1 --port 8000

Или: docker compose up --build -d (с правильно настроенным .env).

Тесты: pip install pytest; pytest -q.

## Подключение AI

Секреты только на сервере, в .env/защищённых переменных окружения:

    AI_MODEL=model
    AI_API_KEY=your-secret
    AI_CHAT_COMPLETIONS_URL=https://provider.example/v1/chat/completions

AI-модель получает фрагменты коммерческих документов; перед отправкой реальных данных необходимо получить разрешение и проверить условия хранения у провайдера.

## Что можно проверить

Загрузите ТЗ и 1–10 КП в формате PDF/DOCX/XLSX/TXT, откройте «Аналитика», посмотрите pass/fail/unknown и скачайте отчёт. Например, «Мощность не менее 5 кВт; Гарантия от 24 мес» и разные предложения.

## GitHub / хостинг

index.html в корне — **статический демо-предпросмотр** (показывает пример чата, но не обрабатывает документы). Рабочий интерфейс находится в app/static/index.html и предназначен для запуска вместе с FastAPI. GitHub сам по себе не запускает Python-сервер; для доступного из интернета приложения нужен HTTPS reverse proxy + сервер/контейнер.

## Безопасность

Это **не готовый к публичному использованию многопользовательский SaaS**. Имеется один общий пароль для тестового рабочего пространства, данные хранятся временно в памяти, нет MFA, RBAC и внешнего пентеста. Подробнее: SECURITY.md. Не загружайте реальные конфиденциальные предложения в публичные демонстрационные окружения. Результат анализа требует проверки специалистом.


## Локальная нейросеть — Ollama

Режим без облачного API: `compose.local.yml` + Qwen2.5 7B Instruct. Запуск, ограничения и меры защиты описаны в [docs/LOCAL_AI.md](docs/LOCAL_AI.md). Система рассчитана на **до 10 КП** в одной загрузке. Важно: для текущей версии проверки числовых критериев детерминированы, нечисловые замечания языковой модели предварительны; журналы правок и соответствие 152-ФЗ пока не реализованы.

## Быстрое устранение тайм-аутов Gemini (пилот)
Статус «AI настроен» означает только наличие настроек, а не ответ Google.
Если основная модель недоступна, можно установить на сервере
`GEMINI_FALLBACK_MODEL=gemini-3.5-flash-lite`.
После сетевой паузы примерно 30 секунд или HTTP 502/503/504 система пытается
получить ответ через резервную модель. Ошибки ключа 401/403 и лимита 429
**не обходятся**; API-ключ остаётся на Render. После выдачи первой части ответа
автоматического переключения модели нет во избежание дублирования.
Резервная модель может иметь другую стоимость, доступность и качество ответов.
При анализе закупок выводы AI остаются предварительными, а числовые проверки
выполняет `app/analysis.py`.


## Workspace v3 — объяснимый отчёт и управление требованиями

Рабочий сайт: https://krakenai-preview-server.onrender.com

- Карточка рекомендованного поставщика с фактической стоимостью, сроком и числом выполненных обязательных условий.
- Интерактивная матрица с оригинальными цитатами, статусом проверки и фильтром нарушений. Большие матрицы разбиты на страницы.
- Для общего локального анализатора: ручное уточнение названия параметра, условия и обязательности. Пересчёт создаёт новую версию, оригинальный текст ТЗ/КП и предыдущий результат остаются неизменными. Специализированные шаблоны пока редактируются только через исходные документы.
- PDF и Excel содержат основания проверки, ручные уточнения; Excel включает лист вопросов поставщикам.
- Кнопка «Сохранить на устройстве» сохраняет отчёт (не исходные файлы) в браузере после согласия пользователя, на 14 дней, до пяти отчётов. Локальный архив работает в той же защищённой сессии; при выходе удаляется. После перезапуска сервера сохранённый отчёт доступен для просмотра, JSON и печати/PDF; для пересчёта и чата нужно заново загрузить документы. Это не серверная база и не межустройственная синхронизация.
- В публичной версии настроены favicon, Open Graph, Twitter Card, canonical и robots.txt. Анализы и API требуют авторизации и не индексируются.

### Локальный анализ

На текущем Render внешний AI отключён. Python проверяет условия, BM25 находит исходные строки; E5 Small работает отдельно в ограниченном по ресурсам процессе. Если E5 недоступен, отчёт сохраняется. Нейросетевой поиск не превращает сходство текстов в балл соответствия.

### Исследовательская выборка

Файл benchmarks/workspace_synthetic_50.json — 50 искусственных закупочных комплектов (10 тематик, 5 вариантов), 100 КП, 300 проверок. Заданы эталонные статусы, релевантные строки и победитель. Это не 50 независимых реальных закупок: варианты используют общие шаблоны. Эксперимент не заменяет проверку на независимых реальных документах.

    python -m app.workspace_benchmark --models bm25 e5 hybrid --output benchmark_results.json

Скрипт измеряет покрытие исходных строк критериев, macro-F1 статусов, точность допуска и победителя, Recall@3, MRR@3, nDCG@3. Старый числовой бейзлайн оценивается на той же выборке. Метрика покрытия строк не доказывает корректное разбиение произвольных составных требований.

Опциональный локальный Cross-Encoder (не включён в бесплатный веб-сервис):

    pip install -r requirements-reranker.txt
    python -m app.workspace_benchmark --models hybrid cross_encoder --cross-model /path/to/local-cross-encoder

Перед запуском самостоятельно скачайте совместимую мультиязычную модель, например mmarco-mMiniLMv2-L12-H384-v1, в локальную папку. Сначала гибридный E5+BM25 выбирает до 8 фрагментов, затем Cross-Encoder оценивает пары «критерий — фрагмент». Проверка чисел и допуск остаются независимыми. Для Cross-Encoder нужны дополнительные ресурсы, его результаты необходимо измерять отдельно; сайт не скачивает эту модель при запросах.

# SECURITY — KrakenAI prototype

## Уже предусмотрено
- CSP, X-Frame-Options, nosniff, no-referrer, HSTS и Secure cookie в production.
- HttpOnly / SameSite Strict cookie; токены сессий хранятся как SHA-256 хеши.
- Проверка Origin + заголовок X-Kraken-Request для изменяющих запросов.
- Авторизация каждого анализа по сессии, лимиты запросов и попыток входа.
- Ограничения типов и размеров файлов, проверка магических байтов, ZIP-лимиты, отдельный subprocess парсер, очищенное окружение.
- Экранирование текста в UI, защищённый CSV экспорт, предварительное подтверждение LLM-цитат.
- Docker user nonroot, read-only filesystem и drop ALL capabilities.
- GitHub Actions: тесты, pip-audit, Bandit.

## Ещё требуется перед публичным доступом
- Персональная аутентификация + RBAC/MFA, безопасное хранилище, шифрование и удаление данных.
- Изолированный контейнер парсера без сети, seccomp/AppArmor и антивирус/CDR для файлов.
- Распределённые rate limits, аудит действий, журналы без секретов, правильная настройка reverse proxy.
- Внешний пентест (XSS, CSRF, IDOR, SSRF, обработка zip-bombs и PDF active content).
- Проверка договоров/расположения серверов AI-провайдера, если используются реальные коммерческие документы.
- OCR для сканов и тестирование ошибок интерпретации сложных технических требований.

Не добавляйте пароли/ключи в Git. Для production установите APP_ENV=production, PUBLIC_ORIGIN=https://... и HTTPS. Не считать результаты AI окончательным решением.

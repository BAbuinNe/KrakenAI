# SECURITY

Это демонстрационный интерфейс. Он **не предназначен для передачи реальных коммерческих предложений**. В `index.html` нет подключения к серверу, а ответы носят демонстрационный характер.

До публикации рабочего сервиса нужны: защищённый Python API, изолированная обработка файлов, ограничение размеров и типов файлов, защита от вредоносных документов, индивидуальная аутентификация, изоляция данных разных пользователей, шифрование и аудит действий. Проверяйте результаты анализа человеком.

Не коммитьте `.env`, токены, пароли и реальные документы поставщиков. Отдельно проведите тесты на уязвимости и утечки.
